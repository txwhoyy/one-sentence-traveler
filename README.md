An entry for [One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) on make.fun.

The program writes exactly one sentence — explaining the modern internet to a time traveler from 1800 — to `/output/entry.txt`. It builds only from things a person from 1800 already knows: a road from your own door that reaches every library and post office on earth, and a letter sent down that road that arrives before your candle gutters — the library, the post office, and the instant reply, all in one picture.

## Run

```sh
node main.ts
```

This validates the sentence (non-blank, single line, at most 200 characters), creates `/output` if needed, and writes the sentence plus a trailing newline to `/output/entry.txt`.
